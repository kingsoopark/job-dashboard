## 2. 기획 배경과 이슈 분석

### 2-1. 모티브 이슈

2026-11-19은 수능일입니다. 수능이 끝나면 수험생은 오래 미룬 게임으로 돌아오는 대표적인 복귀 집단이 됩니다. 러쉬플러스의 주 이용층(10대)과도 겹치므로, "시험 끝, 이제 달릴 시간"이라는 정서를 상품 컨셉으로 삼았습니다.

### 2-2. 검토 후 제외한 후보

| 후보 | 제외 이유 |
|---|---|
| 안세영 코리아오픈 우승 | 실존 인물의 이름·초상을 사용할 수 없음 |
| 지스타 2026 | 넥슨이 대형 부스에 불참해 현장 연계가 어려움 |
| 붕어빵 가격(팥값 급등) | 확인된 기사가 2025년 말 자료 |
| 수능 금지곡류 밈 | 확인된 밈이 2025년 11월 자료, 저작권 문제 |
| 증시 급락, 배달앱 과징금 | 금융 손실·규제 이슈라 게임 상품 모티브로 부적절 |

> 수능 관련 보도(AI 커닝 우려, 시험 연기 요구 등)는 제목 수준으로만 확인했습니다. 이 논란은 상품 컨셉에서 의도적으로 제외합니다.

### 2-3. 기존 운영 콘텐츠와의 관계

러쉬플러스는 현재 시즌 42 '비밀화원'(환상의 공간 테마)을 운영 중입니다. 이번 상품은 시즌 테마와 별개의 현실 이슈형 한정 상품이며, 시각 컨셉과 노출 위치가 겹치지 않게 설계합니다. 시즌 일정과의 충돌 여부는 확인이 필요합니다.

## 3. 아이템 컨셉

**번들명: 「자유 질주 패키지 : 마침표 레이서」**

수능을 직접 언급하는 대신 "시험 후 해방"으로 일반화해, 응시 여부와 점수에 상관없이 누구나 공감하게 합니다.

**하는 것**

- 답안지, OMR, 연필, 시험지 모티브를 카트바디에 입힘
- 밝고 가벼운 해방감의 톤
- 모든 구성품은 외형 전용

**하지 않는 것**

- 실제 수능 문항, 로고, 기관 표기
- 점수, 낙방, 경쟁을 연상시키는 요소
- AI 커닝 등 논란 소재

- 단일 상품, 정가 판매로 구조를 단순하게 유지해 충동 구매 부담을 낮춥니다.
- 스킨이 핵심 가치이고, 꾸미기 3종이 번들 가치를 높입니다.
